# Results

Figures and tables produced by scripts. Every file name starts with the ID of the task that made it, so
anyone can trace it back: `figures/P2-02_premium_breaks.png`, `tables/P2-03_event_table.csv`.
Never edit a result by hand; change the script and re-run it.

```
figures/   charts (PNG for the deck, 300 dpi)
tables/    CSV tables
agentic/   extension A: protocol, team estimate, one folder per agent run
review/    red-team notes
```
