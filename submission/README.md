The scripts are copies of the research code with a standard header, a root-path adjustment for this directory, and trailing whitespace removed; their source SHA-256 values are in those headers. Regenerate them with `.venv/bin/python scripts/p5_04_export.py` from the repository root.

## Reproduction check

Run `.venv/bin/python scripts/p5_04_reproduce.py`. It copies `data/raw/` into an empty temporary workspace, runs all 18 exports (19 commands, because `p3_20_live.txt` has two read-only modes), compares the six deck charts pixel by pixel, and checks the frozen placebo and transfer tables. Its report is `submission/reproduction.json`.

P5-04 found that P2-03's fixed RNG seed was insufficient: weekday quotas came from a Python set with variable iteration order. The explicit weekday order in `scripts/p2_03_events.py` now reproduces the frozen placebo sample and the R$ 35.5 million maximum in F-025. The frozen results did not change. The checked-in `P2-03_event_table.csv` has an older source description for E-05; the current source-checked description is longer. Its event coding and numerical values reproduce, allowing for floating-point rounding below 1e-12 in `p_param`.
